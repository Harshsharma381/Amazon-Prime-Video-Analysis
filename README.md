\# Amazon Prime Movies and TV Shows Analysis



\## Project Overview



This project focuses on analyzing Amazon Prime Video Movies and TV Shows using Python and data analysis libraries.



The objective is to explore content distribution, popular genres, top countries, release trends and content ratings.



\## Dataset



Amazon Prime Movies and TV Shows dataset by Shivam Bansal (Kaggle).



\## Tools and Libraries Used



\- Python

\- Pandas

\- NumPy

\- Matplotlib

\- Seaborn

\- Jupyter Notebook



\## Data Cleaning



\- Handled missing values in selected columns.

\- Checked duplicate records.

\- Prepared the dataset for analysis.



\## Exploratory Data Analysis



The following analysis was performed:



1\. Movies vs TV Shows

2\. Top 10 Genres

3\. Top 10 Countries

4\. Content Released by Year

5\. Content Ratings Distribution

Five graphs were created and saved in the Visualizations folder.
